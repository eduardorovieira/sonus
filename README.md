# 🎵 SONUS

O **SONUS** é uma aplicação web focada em produtividade e bem-estar, projetada para fornecer ambientes sonoros imersivos que auxiliam no foco, relaxamento e meditação.

---

## 🚀 Tecnologias Utilizadas

- **React**
- **Vite** 
- **JavaScript (ES6+)** 
- **CSS3 / CSS Modules** 
- **Google Cloud / Firebase Firestore (API REST)**
- **Vercel**

---

## ✨ Funcionalidades

- 🎛️ **Player Dinâmico:** Reprodução de sons.
- 🔁 **Loop Sem Engasgos:** Reprodução contínua otimizada para sons de fundo.
- 🏷️ **Filtro por Categoria:** Navegação rápida entre categorias.
- 🌙 **Suporte a Tema Escuro:** Alternância de temas (Light/Dark) com persistência de preferência via `localStorage`.
- 📱 **Interface Responsiva:** Layout adaptável para telas móbiles e desktop.
